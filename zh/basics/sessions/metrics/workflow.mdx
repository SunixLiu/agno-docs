在 Agno 中运行工作流时，返回的响应（**WorkflowRunOutput**）包含该次执行的详细指标。

这些指标可帮助你了解 Token 使用情况、执行时间、整体性能，以及工作流中所有智能体、团队和自定义函数在各步骤层面的详细信息。

指标在多个层级上提供：

- **按工作流（Per workflow）**：每个 `WorkflowRunOutput` 包含一个 metrics 对象，其中记录了整个工作流的执行时长。  
- **按步骤（Per step）**：每个步骤都有自己的指标，包括执行时长、Token 消耗和模型信息等。  
- **按会话（Per session）**：会话指标会聚合该会话中所有运行内各步骤的指标总和。

## 示例用法

以下是如何访问和使用工作流指标的方法：

```python
from agno.agent import Agent
from agno.db.sqlite import SqliteDb
from agno.models.openai import OpenAIChat
from agno.team import Team
from agno.tools.duckduckgo import DuckDuckGoTools
from agno.tools.hackernews import HackerNewsTools
from agno.workflow import Step, Workflow
from rich.pretty import pprint

# Define agents
hackernews_agent = Agent(
    name="Hackernews Agent",
    model=OpenAIChat(id="gpt-4o-mini"),
    tools=[HackerNewsTools()],
    role="Extract key insights from Hackernews posts",
)

web_agent = Agent(
    name="Web Agent",
    model=OpenAIChat(id="gpt-4o-mini"),
    tools=[DuckDuckGoTools()],
    role="Search the web for latest trends",
)

# Define research team
research_team = Team(
    name="Research Team",
    members=[hackernews_agent, web_agent],
    instructions="Research tech topics from Hackernews and the web",
)

content_planner = Agent(
    name="Content Planner",
    model=OpenAIChat(id="gpt-4o"),
    instructions="Plan a content schedule based on research",
)

# Create workflow
workflow = Workflow(
    name="Content Creation Workflow",
    db=SqliteDb(db_file="tmp/workflow.db"),
    steps=[
        Step(name="Research Step", team=research_team),
        Step(name="Content Planning Step", agent=content_planner),
    ],
)

# Run workflow
response = workflow.run(input="AI trends in 2024")

# Print workflow-level metrics
print("Workflow Metrics")
if response.metrics:
    pprint(response.metrics.to_dict())

# Print workflow duration
if response.metrics and response.metrics.duration:
    print(f"\nTotal execution time: {response.metrics.duration:.2f} seconds")

# Print step-level metrics
print("Step Metrics")
if response.metrics:
    for step_name, step_metrics in response.metrics.steps.items():
        print(f"\nStep: {step_name}")
        print(f"Executor: {step_metrics.executor_name} ({step_metrics.executor_type})")
        if step_metrics.metrics:
            print(f"Duration: {step_metrics.metrics.duration:.2f}s")
            print(f"Tokens: {step_metrics.metrics.total_tokens}")

# Print session metrics
print("Session Metrics")
pprint(workflow.get_session_metrics().to_dict())
```

你将看到包含以下信息的输出：

**工作流层级指标（Workflow-level metrics）：**
- `duration`：整个工作流的执行总时长（秒），从开始到结束，包括编排开销  
- `steps`：一个字典，将各步骤名称映射到其对应的步骤级指标  

**步骤层级指标（Step-level metrics）：**
- `step_name`：步骤名称  
- `executor_type`：执行器类型（`"agent"`、`"team"` 或 `"function"`）  
- `executor_name`：执行器名称  
- `metrics`：执行指标，包括 Token 消耗、执行时长和模型信息（详见 [Metrics 结构定义](/reference/agents/metrics)）  

**会话层级指标（Session metrics）：**
- 聚合该会话中所有运行的步骤级指标（Token、时长等）  
- 仅包含智能体/团队的执行时间，**不包含**工作流编排本身的开销
